# Unofficial Andee Hindi test APK

This **public download branch** is only for publishing an unofficial personal Android test build. It is not the original KUAFUAI release and is not a Google Play–reviewed app. The original source is [kuafuai/andee at v0.11.0](https://github.com/kuafuai/andee/tree/v0.11.0).

**Download after the build completes:** [Andee_Hindi_Consent_Reviewed_ARM64.apk](downloads/Andee_Hindi_Consent_Reviewed_ARM64.apk)

- Retains Andee name, icon, copyright and license.
- Modifications: Hindi UI and voice-related settings, a non-floating fallback screen, explicit in-app Accessibility consent check and basic bank/payment/trading/wallet exclusions.
- **Safety warning:** This app has sensitive Accessibility capabilities to read and control Android screens. The exclusions are heuristic and NOT a security guarantee, particularly in browsers. Do not use while viewing passwords, private keys, OTPs, bank or payment screens. Disable Accessibility for sensitive tasks.
- **Play Protect:** Android may still block sideloaded APKs with sensitive services. Do not disable Play Protect or bypass security safeguards.
- The APK is debug signed, has not been security audited, and has not been tested on a realme NARZO handset.
- AI models or backend credentials are not bundled; using Andee's AI agent requires configuring an appropriate backend.
- Distribution is under Andee's included modified Apache-2.0 license; see [LICENSE](LICENSE). This is not an official KUAFUAI release. No endorsement implied.
- This branch is independent of the connected private repo. No private source/project keys are published.

The source build scripts are included so the build can be reproduced.
